# UI/UX Design Rules

These rules are mandatory for every UI change in this project.

## Readability First

Never sacrifice readability for visual compactness.

* Body text must normally be at least 15–16px.
* Secondary/supporting text should normally be at least 14px.
* Never use tiny text just to fit more content on screen.
* Avoid text sizes below 14px unless there is a strong and specific UI reason.
* Important information must have sufficient visual contrast.
* Do not use extremely light gray text on light backgrounds.
* Text must remain clearly readable on normal laptop and desktop displays.
* Line height must be comfortable and appropriate for the font size.
* Never make text unnecessarily narrow, condensed, or cramped.

## Typography

Use a clean, professional, highly readable font.

* Do not randomly introduce fonts.
* Use the project's existing font system consistently.
* Maintain a clear hierarchy between:

  * Page title
  * Section heading
  * Body text
  * Secondary text
  * Labels
  * Metadata
* Do not make typography decorative just for visual novelty.

## Spacing

* Give text enough breathing room.
* Do not place text too close to buttons, borders, icons, or other content.
* Avoid extremely tight vertical spacing.
* Use a consistent spacing scale throughout the application.

## Visual Hierarchy

Every page must have an obvious hierarchy.

The user should immediately understand:

1. What page they are on.
2. What the most important information is.
3. What the primary action is.
4. What information is secondary.

Do not make every element visually equally important.

## Avoid Generic AI UI

Do NOT automatically use:

* excessive rounded cards
* excessive gradients
* glassmorphism
* random shadows
* tiny muted text
* unnecessary icons
* excessive badges
* decorative elements with no UX purpose
* dense layouts that resemble generic AI-generated dashboards

## Before Finishing Any UI

Visually inspect the result and ask:

* Is any text difficult to read?
* Is any text unnecessarily small?
* Is the contrast sufficient?
* Is the spacing comfortable?
* Is the hierarchy obvious?
* Does anything look like it was added only for decoration?
* Does this look like a professionally designed product rather than an AI-generated template?

If something looks visually questionable, fix it before considering the task complete.

Do not merely satisfy the functional requirements. The final result must have strong UX, typography, readability, spacing, and visual hierarchy.
