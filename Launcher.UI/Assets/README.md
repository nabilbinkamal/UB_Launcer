# UB Launcher image placeholders

No image assets are generated by the launcher UI. Replace these placeholder locations with local files or Supabase Storage / Cloudflare R2 URLs:

- Hero banner: `C:\UBLauncher\Assets\hero-banner.png`
- Partner server icon: `C:\UBLauncher\Assets\partner-server.png`
- Discord artwork: `C:\UBLauncher\Assets\discord-banner.png`
- Launcher logo: `C:\UBLauncher\Assets\ub-launcher-logo.png`

The dashboard intentionally shows the hero path as text until a real asset URL is configured.
